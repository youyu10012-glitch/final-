# 또박또박

## 팀원 및 역할 분담

- 오주현 (PM / AI): 프로젝트 설계, 프롬프트 스키마 구성, AI 에이전트 통합 및 코드 리뷰
- 황지영 (LLM / Vision): 멀티모달 추출, 비전 기반 문서 파싱, 금액/일자/기한 등 핵심 정보 3색 표시 기준 설계
- 이정관 (Backend): 배포 자동화, 백엔드 API 구성, 기한 알림 및 자동화 워크플로우 구축
- 송유영 (Frontend): 모바일 화면 UI 구현, 3색 오버레이 표시, 할 일 카드 화면 구성, 손주 모드 화면 구현
- 김기훈 (RAG / Data Quality): 데이터 수집, 공문 문서 정리, 테스트셋 구성, 정확도 분석 및 품질 검증
- 송유진 (UX): 사용자 테스트 기획, 쉬운 말 풀이 문체 가이드 작성, 시연 영상 및 발표 자료 준비

## 프로젝트 소개

또박또박은 공문을 읽기 어려워하는 사용자가 원문 위에 핵심 정보를 직관적으로 확인할 수 있도록 도와주는 서비스입니다. 사용자는 사진 속 공문을 분석해 금액, 기한, 제출 서류 등을 한눈에 파악하고, 일정을 할 일 카드 형태로 정리할 수 있습니다.

## 핵심 기능

- 3색 오버레이로 금액, 기한, 서류 정보를 시각적으로 표시
- 공문 원문과 근거 문장을 함께 확인하는 해석 기능
- 할 일 카드 기반의 체크리스트형 일정 정리
- 손주 모드로 보호자/자녀가 공문 내용을 쉽게 확인하고 응답 준비 가능
